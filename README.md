# Login Page

Tela de login responsiva feita com HTML, CSS e JavaScript, criada para estudar os fundamentos de desenvolvimento front-end.

## Demonstração

https://henriqueesantana.github.io/login-page/

## Funcionalidades

- Layout dividido em duas colunas: imagem de um lado e formulário do outro
- Validação do formulário com JavaScript (e-mail e senha)
- Mensagens de erro que aparecem e somem dinamicamente
- Botão para mostrar e esconder a senha
- Layout responsivo, que se adapta a celulares e telas menores
- Links para redes sociais (GitHub, Instagram e LinkedIn)

## Tecnologias

- HTML5
- CSS3 (Flexbox, variáveis CSS e media queries)
- JavaScript (manipulação do DOM e eventos)
- Ionicons (ícones)

## Estrutura do projeto

```
login-page/
  index.html
  style.css
  script.js
  img/
    login.png
```

## Como executar

1. Baixe ou clone o repositório:

```
git clone https://github.com/HenriqueeSantana/login-page.git
```

2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nada. Os ícones carregam pela internet, então é preciso estar conectado.

## Observações

Este é um projeto de estudo. O formulário apenas simula o envio e não faz autenticação real, pois não há servidor (backend).
